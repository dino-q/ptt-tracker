# PTT Assistant

> **想知道怎麼用？看 [`使用說明.md`](使用說明.md)**（線下版啟動、線上版網址、功能與差異）。
> 本檔是開發沿革與技術紀錄。

這是一個 Windows / macOS / Linux 都能執行的 Python 小工具，目標是讓你直接用一句中文要求整理 PTT。
線上版：https://dino-q.github.io/ptt-tracker/（GitHub Actions 自動更新）。

## v2.3 更新（2026-09-03）：免費圖片優惠文字辨識

- 省錢版文章若只貼圖片網址，GitHub Actions 會用開源 **Tesseract OCR** 擷取繁體中文與英文，不呼叫付費圖片分析 API。
- 優惠海報會先校正方向、放大小字與增強對比，再以「散落文字」與「整齊區塊」兩種版面模式辨識；依文字座標保留換行和區塊，降低日期、價格、品項、限制條件互相錯接。
- 辨識內容會以「圖片文字辨識」區塊併入摘要與全文，也會參與通路分類；OCR 可能誤讀，畫面會保留原圖與原文連結供核對。
- 每輪最多檢查 12 篇、每篇最多 2 張圖，已檢查結果會沿用，避免每小時重複辨識舊圖片；單次辨識與整個 Actions 工作也都有逾時上限。
- 為避免文章中的惡意網址探測內網，只自動下載常見且固定的公開圖床（Imgur、Mopix、Catbox、ImgPoi、ImgBB、X/Twitter 圖片、Bahamut、Upload.cc）；其他網址仍保留在原文，但不由伺服器自動下載。
- 本機未安裝 Tesseract 時會安全略過 OCR，一般 PTT 掃描不受影響；線上版排程已自動安裝繁體中文語言包。

## v2.2 更新（2026-08-22）：依功能分頁重設計

- 介面重組成四個功能頁：**省錢優惠**（分類頁籤總覽＋週末咖啡按鈕）、**熱門文章**（全站/單板）、**作者下載**、**進階掃描**（通用條件＋自訂追蹤項）。
- **批次下載全文**：任何結果清單（含分類/文字過濾後的子集）都可一鍵抓全文合併成 TXT，可勾「含留言」，完成後瀏覽器直接下載（也存一份在 `output/`）。
- 白話輸入升為全域入口：解析後自動切到對應功能頁並填好條件。
- 自動更新紀錄寫在 `data/refresh.log`（排程無視窗，除錯看這裡）。

## v2.1 更新（2026-08-22）

- **開頁即看**：省錢版總覽與全站熱門有每日自動更新的快取，開頁面直接顯示最新結果（顯示更新時間），不用按掃描。點追蹤項名稱可隨時切換看各自的快取。
- **省錢版分類頁籤**：全部／四大超商／超市量販／網購電商／餐飲美食／支付回饋／其他（一篇可屬多類）。分類詞可在 `config.json` 的 `categories` 覆蓋。
- **作者文章匯出模式**：白話輸入「幫我上PTT的movie版找abc123這個作者，並且把他的創作做成txt檔」→ 自動切到作者模式 → 匯出集數排序的合併 TXT 到 `output/`。
- **熱門討論模式**：「當前PTT的熱門討論」＝人氣前 10 板、「八卦版有什麼爆文」＝單板。用 PTT 原生 `recommend:` 搜尋（快板沉下去的熱文也抓得到），Re: 討論串聚合，讀取留言統計後依「衝火速度」排序（總留言數÷時間衰減），可切換總留言數；分類為看板主題（八卦時事/棒球/遊戲電競…）。
- **每日排程**：Windows 排程 `PTT_Assistant_DailyCache` 每日 08:30 無視窗更新快取（搬資料夾前先看 `路徑相依_搬移前必讀.md`）。

## v2.0 網頁介面（2026-08-22 新增，建議用這個）

雙擊 `啟動.bat`（標準入口；會轉交既有 `PTT工具.bat`）→ 直接按 Enter（模式 1），會啟動本機伺服器並自動開瀏覽器：

```text
http://127.0.0.1:8877
```

功能：

- **白話需求**：輸入「我想看省錢版這週五六日超商咖啡或飲料有什麼優惠」→ 按「解析」→ 自動填好掃描條件 → 確認後「開始掃描」。
- **通用掃描**：任何看板（英文板名）＋搜尋關鍵字＋「必含條件」關鍵字組（一行一組，每組至少命中一詞才收錄）＋排除詞＋只看最近 N 天。
- **追蹤項**：條件調好後可存成追蹤項，之後一鍵重跑。內建「省錢版｜週五六日超商咖啡/飲料優惠」。
- **結果**：卡片顯示標題/日期/命中關鍵字，可展開內文摘要、再過濾、匯出 TXT（存到 `output/`）。

手動啟動（不經 bat）：

```bat
.venv\Scripts\python.exe server.py            rem 預設 port 8877
.venv\Scripts\python.exe server.py --port 8878 --no-browser
```

追蹤項存在 `tracks.json`（首次啟動自動建立），可直接手改。
程式碼地圖見 `docs/CODE_MAP.md`。

## 你要的兩個情境

### 1. 找某個板某位作者的創作並整理成 TXT

在資料夾內執行（以 movie 板作者 abc123 為例）：

```bat
python ptt_tool.py "幫我上PTT的movie版找abc123這個作者，並且把他的創作做成txt檔"
```

工具會：

1. 解析 `movie版` → `movie`
2. 解析作者 `abc123`
3. 使用 PTT 原生 `author:abc123` 搜尋
4. 篩選標題含 `[創作]` 的文章
5. 逐篇讀取文章
6. 去除 PTT 標頭、推文、發信站資訊
7. 依標題中的集數盡量排序
8. 合併成 UTF-8 BOM TXT（Windows 記事本可直接看）

輸出在：

```text
output/abc123_movie_創作.txt
```

也可使用明確參數：

```bat
python ptt_tool.py --board movie --author abc123
```

---

### 2. 找這週五六日超商咖啡／飲料優惠

```bat
python ptt_tool.py "幫我找這週五六日超商咖啡或飲料優惠"
```

或：

```bat
python ptt_tool.py --weekend-deals
```

工具會掃描 PTT `Lifeismoney`（省錢板），搜尋：

- 咖啡
- 飲料
- 全家
- 7-11 / 統一超商
- 萊爾富
- 康康五
- 超值五六日

並從候選文章內再次確認是否同時涉及「超商」與「咖啡／飲料」語意。

輸出例如：

```text
output/Lifeismoney_週末咖啡飲料優惠_20260821-20260823.txt
```

> PTT 優惠文章可能會提前數天發布，實際活動日期、門市、會員條件仍要以官方資訊為準。

## 安裝

### Windows 最簡單方式

1. 安裝 Python 3.11 以上版本。
2. 解壓縮這個資料夾。
3. 雙擊 `安裝.bat`（會轉交既有 `安裝套件.bat`）。
4. 之後雙擊 `啟動.bat`。

或者在命令提示字元執行：

```bat
pip install -r requirements.txt
```

## 一句話模式

```bat
python ptt_tool.py "你的要求"
```

目前會優先理解：

- 任何「XX版 / XX板」寫法（英文板名或內建別名）
- `省錢版 / Lifeismoney`
- `找 XXX 這個作者`
- `作者 XXX`
- `小說 / 創作 / 做成 txt / 匯出`
- `這週五六日 / 週末`
- `超商 / 咖啡 / 飲料`

其他要求會退回成一般 PTT 板面關鍵字搜尋並輸出索引 TXT。

## 自訂板面搜尋

```bat
python ptt_tool.py --board Lifeismoney --query "全家 咖啡"
```

## 輸出位置

預設：

```text
output/
```

也可以指定：

```bat
python ptt_tool.py --out "D:\PTT" "幫我找這週末咖啡優惠"
```

## 對 PTT 友善

預設每次 HTTP 請求後等待 0.8 秒，避免短時間大量請求。

想更保守：

```bat
python ptt_tool.py --delay 1.5 "你的要求"
```

## 注意事項

- 此工具只讀取 PTT 公開網頁，不登入帳號、不發文、不推文。
- PTT 網頁結構未來若變更，CSS selector 可能需要更新。
- 請遵守 PTT 使用規範及你所在地適用的法律與內容授權條件。
- 省錢板內容為網友整理，優惠仍應以品牌／通路官方公告為準。


## v1.1 Windows 安裝修正

如果舊版 `安裝套件.bat` 會閃退，請使用 v1.1。

新版會：

- 自動切換到工具所在資料夾。
